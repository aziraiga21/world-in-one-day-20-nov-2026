# The World in One Day

A 1024 × 1024 newspaper front page for Friday 20 November 2026, with 37 supplied stories, original illustrations, and a numbered world map drawn in Pillow.

- Run `python3 draw.py` to regenerate `entry.png` with Python 3 and Pillow.
- Run `python3 main.py` to copy the PNG to `MAKEFUN_OUTPUT_DIR`, which defaults to `output`.
